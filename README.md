# 💡 Dark Room — Boba Bash

An interactive web project built around the theme **"Dark"** for boba bash delhi.

## 🛠️ Tech Stack
- **HTML5:** Semantic layout and DOM structure.
- **CSS3:** Dark to warm light ambient gradients, glowing effects, and smooth opacity transitions.
- **Vanilla JavaScript:** 4-line event listener toggling the `.light-on` state.
